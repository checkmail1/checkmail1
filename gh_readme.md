# CheckMail1

**Email verification API for developers** — https://checkmail1.com

Real-time REST API to validate email addresses:
- Syntax, domain, MX and SMTP checks
- Provider-specific deliverability verification for **Gmail, Outlook, Yahoo and iCloud**
- Role, catch-all and disposable-domain detection
- Bulk CSV verification

OpenAPI spec: https://checkmail1.com/openapi.json
