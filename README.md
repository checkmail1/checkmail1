# CheckMail1 — Email Verification API

Accurate email verification for Gmail, Outlook, Yahoo, iCloud and 150+ providers.

## Why CheckMail1?

Most email verification APIs return "unknown" for Gmail and iCloud because they block standard SMTP probes. CheckMail1 uses provider-specific logic to return accurate results.

## Features

- ✅ Gmail, Outlook, Yahoo, iCloud verification
- ✅ 150+ email providers supported
- ✅ Disposable email detection
- ✅ Role-based email detection (info@, support@)
- ✅ MX record validation
- ✅ 99% accuracy

## Quick Start

bash
curl 'https://checkmail1.com/api/verify?email=test@gmail.com' \
  -H 'Authorization: Bearer YOURAPIKEY'
